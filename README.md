# DevArchive
This Chrome extension for the Amazon Mentorship Program helps developers who frequently search for the same coding problems. It identifies recurring issues, suggests previously looked answers to the questions.
Uses TF-IDF to create embedding vectors for websites that you save. The embeddings are saved to local storage. When you do a search in your browser, it compares you query to the saved embeddings and if a close match appears it recommends the website you saved before to you as a potential answer to the query that you made.
